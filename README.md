# 月光河互動小遊戲

這是一個以國小國語第七課〈月光河〉為素材的靜態互動網頁遊戲，適合用來複習課文、部首、字族、語氣詞、句型與聆聽理解。

## 內容

- 故事排序
- 部首連連看
- 「昔」字家族填字
- 「一定 / 可能」語氣判斷
- 「除了……都……」句子重組
- 聆聽理解問答

## 本機開啟

直接用瀏覽器開啟 `index.html` 即可遊玩。

## 發佈到 GitHub Pages

1. 將此資料夾推送到 GitHub repository。
2. 進入 GitHub repository 的 `Settings`。
3. 選擇 `Pages`。
4. 在 `Build and deployment` 選擇 `Deploy from a branch`。
5. Branch 選擇 `main`，資料夾選擇 `/root`。
6. 儲存後等待 GitHub 產生網站網址。

## 檔案

- `index.html`：網頁結構
- `styles.css`：畫面與響應式設計
- `app.js`：遊戲題庫與互動邏輯
